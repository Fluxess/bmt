# BMT — баллы групп техникума

VK Mini App / сайт для учёта баллов учебных групп. Хостинг без своего домена: GitHub Pages.

## Открыть

- Сайт: https://fluxess.github.io/bmt/
- Политика: https://fluxess.github.io/bmt/privacy/
- Репозиторий: https://github.com/Fluxess/bmt

## Что умеет

- Группы: создание, переименование, удаление; пресет из расписания [bumate.ru/schedule](https://bumate.ru/schedule)
- Студенты: добавление по одному или списком, переименование, удаление
- Баллы: начисление/списание по категориям (учёба, дисциплина, мероприятия, прочее)
- Рейтинг, поиск по ФИО, фильтр по категориям
- Отмена операций с баллами
- Альбом группы: грамоты, фото группы, мероприятия
- Бэкап и восстановление JSON
- Экспорт рейтинга в CSV
- Поделиться ссылкой (VK Bridge или буфер обмена)

Данные хранятся в `localStorage` на устройстве. Для переноса на другой телефон используйте «Скачать бэкап» → «Восстановить».

## VK Mini App

1. [dev.vk.com](https://dev.vk.com) → создать приложение типа **Mini App**
2. URL приложения: `https://fluxess.github.io/bmt/`
3. URL политики: `https://fluxess.github.io/bmt/privacy/`
4. Открывать через `https://vk.com/appВАШ_ID`

Свой домен, Google Play и App Store не нужны.

## Локальная разработка

Папка `docs/` — статический сайт. Можно открыть `docs/index.html` или любой локальный HTTP-сервер.
