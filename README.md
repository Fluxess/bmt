# BMT — баллы групп техникума

VK Mini App / сайт для учёта баллов учебных групп. Хостинг без своего домена: GitHub Pages.

## Открыть

- Сайт: https://fluxess.github.io/bmt/
- Политика: https://fluxess.github.io/bmt/privacy/
- Репозиторий: https://github.com/Fluxess/bmt

## Что умеет

- Личные кабинеты по должностям: куратор, заведующая, замдиректора, директор, главный админ
- Заявки на регистрацию и создание кабинетов админом
- Куратору прикрепляется своя группа; руководству доступны все группы
- Группы: пресет из расписания [bumate.ru/schedule](https://bumate.ru/schedule)
- Студенты, баллы, рейтинг, альбом, обложка группы
- Бэкап / CSV (для админа)

### Главный админ

- Логин: `dragov`
- Пароль: задан при установке (см. у владельца)

Данные хранятся в `localStorage` на устройстве. Для общей базы между телефонами позже нужен сервер.

## VK Mini App

1. [dev.vk.com](https://dev.vk.com) → создать приложение типа **Mini App**
2. URL приложения: `https://fluxess.github.io/bmt/`
3. URL политики: `https://fluxess.github.io/bmt/privacy/`
4. Открывать через `https://vk.com/appВАШ_ID`

Свой домен, Google Play и App Store не нужны.

## Локальная разработка

Папка `docs/` — статический сайт. Можно открыть `docs/index.html` или любой локальный HTTP-сервер.
