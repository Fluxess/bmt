BMT

Политика конфиденциальности · VK Mini App

Дата: 10 сентября 2026 г.

BMT — учёт баллов учебных групп техникума во ВКонтакте. Данные групп и операций хранятся в браузере устройства (localStorage), отдельный сервер не используется.

Данные

  • Регистрация на нашей стороне: нет.
  • Аналитика и реклама: не подключены.
  • Имя и id видны только если пользователь открыл приложение в VK и платформа отдала их через VK Bridge — это данные VK.

Этот текст укажите в кабинете dev.vk.com как URL политики (страница GitHub Pages без своего домена).
