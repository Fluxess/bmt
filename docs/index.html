Кабинет VK для разработчиков

  1. Откройте dev.vk.com → «Мои приложения» → «Создать» → тип Mini App.
  2. В настройках приложения укажите URL (и URL для разработки) — HTTPS без своего домена, например GitHub Pages: https://ВАШ_ЛОГИН.github.io/bmt/
  3. Не ставьте файл CNAME и не покупайте домен.
  4. Политика: https://ВАШ_ЛОГИН.github.io/bmt/privacy/
  5. Откройте приложение из VK (ссылка вида https://vk.com/appID) — модерация сторов не нужна.
